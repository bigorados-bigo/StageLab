# StageLab v0.1

UNI2 FPAN compiled-stage import, native-look preview, editing and export for
Blender5.0. Documentation: https://github.com/bigorados-bigo/StageLab

Install this folder as a legacy Blender addon, or use the release ZIP in
Preferences > Add-ons > Install from Disk. Enable StageLab, then open
3D View sidebar > FPAN Stage.

Use your own extracted stage assets and retain their textures and BgList
context. Export writes compiled FbxExp `.fbx.bin`, not Autodesk FBX. Existing
vertex positions and placement G/R/S are supported together; topology, edited
Blender animation, constraints/modifiers/shape keys and zero scale are not.

Use Placement editing for object offsets and normal Edit Mode for vertices.
Return to Object Mode and use Export Edited Stage Copy. Existing destinations
are backed up; the exact imported source remains protected. Save your .blend.

Early preview: see the repository's validation scope and known limitations.
No game assets, mod loader or archive patches are included.
