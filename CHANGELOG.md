# Changelog

## 0.1.0 — first public preview

- UNI2 compiled FPAN import, texture resolution and native matrix playback.
- Native-look GPU viewport, locked/free camera modes, fog/composition controls
  and supported scripted PAT effects.
- Existing-vertex editing and persistent placement controls using Blender G/R/S.
- Unified compiled export of vertex positions and affine placement offsets,
  retaining native hierarchy and independent sampled animation cycles.
- Full affine/shear preservation through Blender playback and reimport.
- Standard overwrite confirmation, recoverable backups and atomic replacement.
- Synthetic tests, validation scope and maintainer-oriented implementation map.
